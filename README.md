## Projects

### PiCode

A VSCodium distribution with the [Pi](https://pi.dev) coding agent and [Gentle AI](https://github.com/Gentleman-Programming/gentle-ai) **inside the editor core** — not as a plugin bolted on afterwards.

`@pi` in the chat, providers connected from settings, memory and skills already there. No setup ceremony, no Copilot. Free and complete.

### Gentle AI

Not mine, but central to everything. A review discipline and workflow harness that sits on top of coding agents — memory, skills, ODD (Organic Driven Development), Spec-Driven Development, and structured review. The reason PiCode feels more like a tool than a collection of parts.

## What you'll find here

| | |
| --- | --- |
| **Editor distributions** | Software that doesn't ask you to install things after it. PiCode *is* the environment. |
| **Open source first** | MIT licensed, built on MIT-licensed upstreams (VSCodium, Pi, Gentle AI). No locked-in features, no server dependency. |
| **The messy middle** | Repos where things are compiled, patched, and wired together. You can read the patches, verify every build, and rebuild from source. |
| **Still learning** | There are things I haven't figured out yet. If you spot them, an issue or a PR is welcome. |

## Stack

| Layer | Tools |
| --- | --- |
| **Language** | English, Spanish |
| **Method** | ODD (Organic Driven Development) — SDD/OpenSpec when the spec calls for it |
